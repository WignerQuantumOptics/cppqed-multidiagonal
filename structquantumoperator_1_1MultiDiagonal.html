Detailed Description

template<size_t RANK>
struct quantumoperator::MultiDiagonal< RANK >

A sparse matrix storing an arbitrary set of diagonals, closed under composition, direct product, and Hermitian conjugation.

MultiDiagonal<RANK> supersedes Tridiagonal<RANK> from v2, which stored exactly three diagonals per axis — at positions $-K$, $0$, $+K$ for a single shared offset $K$ — and was not closed under composition: the product of two tridiagonal operators is in general pentadiagonal, and with different offsets not tridiagonal at all. MultiDiagonal lifts all these restrictions:

  • Any number of diagonals at arbitrary offsets per axis.
  • operator| (composition) produces new diagonals at all pairwise offset sums — the algebra is closed.
  • operator* (direct product) concatenates offset arrays, reflecting tensor product structure exactly.

Representation

Each diagonal is keyed by a signed offset per axis: positive = upper, negative = lower, zero = main. The offset map is a homomorphism from \((\mathbb{Z}^R,+)\) into the operator algebra:

  • composition: \(\text{offset}_{A|B} = \text{offset}_A + \text{offset}_B\) (per axis)
  • Hermitian conjugation: negation of all offsets
  • direct product: concatenation of offset arrays

Storage convention. The diagonal at signed offset \(o\) (per axis, dimension \(D\)) has extent \(D-|o|\), and entry \(k\in[0,D-|o|)\) holds the matrix element

\[ d[k] = A_{k+o^-,\;k+o^+}, \qquad o^\pm = \max(\pm o,0). \]

This min(row,col)-anchored indexing is symmetric under transposition, so Hermitian conjugation negates the key and conjugates the values without reindexing. The invariant \(\text{extent}_i + |o_i| = D_i\) holds for every diagonal and is enforced by calculateAndCheckDimensions; entries that are structurally zero (created e.g. by composition) are stored explicitly as zeros to preserve it.

Time dependence

MultiDiagonal is time-independent. Interaction-picture time dependence — diagonal elements of the form \(\alpha_{m,n} e^{\delta_{m,n} t}\) with complex \(\delta\) — is handled by a derived type in CPPQEDcore that adds a parallel frequency MultiDiagonal and propagate(t) bookkeeping. This separation keeps MultiDiagonal a clean, unconditionally time-independent algebraic type.

Operator conventions

  • operator() applies \(H/i\) (not \(H\)) to the state vector, consistent with the framework convention.
  • \(H\) need not be Hermitian: in QJMC and Master equation contexts it is the full effective non-Hermitian Hamiltonian \(H_\text{eff} = H_\text{phys} - \frac{i}{2}\sum_k J_k^\dagger J_k\).
