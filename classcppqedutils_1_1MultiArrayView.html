Detailed Description

template<typename T, size_t RANK>
class cppqedutils::MultiArrayView< T, RANK >

A non-owning, strided view over a contiguous buffer. Should be passed by value.

Follows pointer-like (reference) semantics regarding constness: a const MultiArrayView<T,R> still allows mutation of the underlying data, just as a T* const does. All four combinations of (const) MultiArrayView<(const) T, RANK> are usable.

The flat storage index for multi-index \((i_0,\ldots,i_{R-1})\) is

\[ \text{offset} + \sum_{\iota=0}^{R-1} s_\iota\, i_\iota \]

where \(s\) are the strides and \(\text{offset}\) accumulates from prior slicing.
