Detailed Description

template<typename T, size_t RANK>
requires ( !std::is_const_v<T> )
class cppqedutils::MultiArray< T, RANK >

Owning, move-only, rank-RANK array. Non-copyable; follows value semantics regarding constness.

Derives from MultiArrayConstView<T,RANK> to expose the full view interface. The dataView span in the base is re-seated to data_ after each construction or move.

Note
The storage type std::vector<T> may eventually be replaced by kokkos::View or std::valarray for better HPC integration.
