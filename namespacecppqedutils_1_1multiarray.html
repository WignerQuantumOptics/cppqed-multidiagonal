◆ calculateStrides()

template<size_t RANK>
auto cppqedutils::multiarray::calculateStrides ( Extents< RANK >  extents)

Computes first-index-fastest strides from extents (std::layout_left; column-major for rank 2): strides[0]=1, strides[i]=strides[i-1]*extents[i-1].

This is the memory layout of every owning MultiArray. Note that incrementMultiIndex iterates in the opposite order (last index fastest).

Initializer for storage of size e whose contents the caller overwrites before reading them.

Note
std::vector<T>(e) value-initializes, so the storage is currently zero-filled after all. Don't rely on that: truly uninitialized storage would need a default-initializing allocator.
