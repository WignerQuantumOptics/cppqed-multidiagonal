# 2026-11-03, reference machine: three versions of the library

Measured before `benchmarks/run.sh` existed, with the one-off script [`refrun.sh`](refrun.sh), kept here as it was on the machine.

- **What:** the three suites of the build at hand, and of two older builds the cases and benchmarks they had in common with it; five rounds with the builds alternating, pinned to core 1.
- **Source:** three builds, which the script names only by their directories. `now` is 7725d79 (the script of the next day, `refrun2.sh`, says so of the same build directory), "after #23" on the page. `pre23` and `v040` are, by the page's "Setup", 84cf7d4 ("before #23") and the library of v0.4.0 with the benchmarks of e49319b ("v0.4.0"). All Release, `-march=native`.
- **Machine:** the reference machine of [`performance.md`](../../performance.md), "Setup". Its state at the start and at the end is in `log`. The script did not record the compiler and Eigen versions; the page gives GCC 16.2.1 and Eigen 5.0.1 for the machine at the time.
- **Pages:** as the system handed them out, which on this machine means transparent huge pages for all large arrays; hence `thp` in the file names.
- **Quoted in `performance.md`:** the table of "Complex multiplication", and the columns "v0.4.0", "before #23" and "after #23" of the tables in "The library's two loop shapes".
