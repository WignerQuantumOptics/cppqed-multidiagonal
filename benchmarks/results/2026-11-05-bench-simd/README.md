# 2026-11-05, reference machine: the instruction set

Measured before `benchmarks/run.sh` existed, with the one-off script [`simd.sh`](simd.sh), kept here as it was on the machine.

- **What:** `jc_qjmc` at four cutoffs, `kernels` cases A, B and E, and the main suite's `apply1` and `applyJC`, built three ways: for the x86-64 baseline (`base`), with `-march=x86-64-v3` (`v3`) and with `-march=native` (`native`). On 4 KB pages, five rounds alternating, pinned to core 1.
- **Source:** the library at 14254a1 and C++QED 0a0efb12 with Eigen 3.4.0; `native` is the build of `2026-11-04-bench-remeasure`.
- **Machine:** the reference machine of [`performance.md`](../../performance.md), "Setup". Its state at the start and at the end is in `log`. The script did not record the compiler version; the page gives GCC 16.2.1 for the machine at the time, and Eigen 5.0.1, which the library's benchmarks used.
- **Quoted in `performance.md`:** the section "Instruction set": its table, and the ratios to Eigen at the baseline and with AVX2.
- **`times`:** one line per run of `jc_qjmc`: build, mode cutoff, round, wall time in microseconds, number of derivative calls. The trajectories that the runs wrote are not kept here; they are C++QED's output, not this library's.
- **`regression.*.txt`** and the first lines of `log`: the regression check of `jc_qjmc` and the count of AVX instructions per build, taken before the timing.
