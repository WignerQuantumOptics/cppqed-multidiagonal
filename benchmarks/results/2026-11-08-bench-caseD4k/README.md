# 2026-11-08, reference machine: case D on 4 KB pages

Measured before `benchmarks/run.sh` existed, with the one-off script [`caseD4k.sh`](caseD4k.sh), kept here as it was on the machine.

- **What:** `kernels` case D (a term applied slice by slice to n⁴ states, n = 30 and 32), the default build and the `-fcx-limited-range` build alternating, five processes each, pinned to core 1, on 4 KB pages (`--no-thp`).
- **Source:** e90ea79, Release, `-march=native`.
- **Machine:** the reference machine of [`performance.md`](../../performance.md), "Setup". Its state at the start and at the end is in `log`. The script did not record the compiler and Eigen versions; the page gives GCC 16.2.1 and Eigen 5.0.1 for the machine at the time.
- **Quoted in `performance.md`:** the last three rows of the table in "Operators applied slice by slice", and the slice figures of the summary (2.5–2.6× and 1.5–1.6× against the term CSR; 1.9–2.0× and 1.3–1.4× against its `-fcx-limited-range` build).
