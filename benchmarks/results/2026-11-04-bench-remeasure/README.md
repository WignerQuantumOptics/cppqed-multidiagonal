# 2026-11-04, reference machine: huge pages against 4 KB pages

Measured before `benchmarks/run.sh` existed, with the one-off script [`remeasure.sh`](remeasure.sh), kept here as it was on the machine.

- **What:** `kernels` (cases A–F) and the main suite's `apply1` and `applyJC`, each on huge pages and on 4 KB pages (`--no-thp`), five rounds with the four runs alternating, pinned to core 1.
- **Source:** the library as in c346b8a (v0.4.1), with the benchmarks' `--no-thp` option, which was committed after the session as 14254a1; copied to the machine as `cppqed-multidiagonal-remeasure`, hence the label `remeasure`. Release, `-march=native`.
- **Machine:** the reference machine of [`performance.md`](../../performance.md), "Setup". Its state at the start and at the end is in `log`. The script did not record the compiler and Eigen versions; the page gives GCC 16.2.1 and Eigen 5.0.1 for the machine at the time.
- **Quoted in `performance.md`:** the out-of-cache figures on 4 KB pages, among them the last column of the table of `applyJC` and `apply1` ratios in "The library's two loop shapes" and the 2.0–2.4× and 0.9–1.1× of the summary.

The files were renamed to the layout of `run.sh`, so that `benchmarks/reduce.py` reads them; their contents are unchanged:
