# 2026-11-04, reference machine: the row shape as committed, against 7725d79

Measured before `benchmarks/run.sh` existed, with the one-off script [`refrun3.sh`](refrun3.sh), kept here as it was on the machine.

- **What:** the three suites of the new build, and `kernels` with the main suite's `apply1` and `applyJC` of the previous one; five rounds with the builds alternating, pinned to core 1. Then two placement scans of the row shape at N = 1024.
- **Source:** `step3` is fb8ca7f, the commit of the row shape before its message was amended: its tree is identical to that of c346b8a, under which the commit is in the repository. `prev` is 7725d79. Both Release, `-march=native`.
- **Machine:** the reference machine of [`performance.md`](../../performance.md), "Setup". Its state at the start and at the end is in `log`. The script did not record the compiler and Eigen versions; the page gives GCC 16.2.1 and Eigen 5.0.1 for the machine at the time.
- **Pages:** as the system handed them out, which on this machine means transparent huge pages for all large arrays; hence `thp` in the file names.
- **The scans** (`scan.apply1.1024.byRows.N.csv`) come from a prototype program that is not in the repository. They have no header line; the columns are benchmark, N, loop shape, the offset of `psi` within its page in bytes, and nanoseconds per application.
- **Quoted in `performance.md`:** the "now" columns of the tables in "The library's two loop shapes".
