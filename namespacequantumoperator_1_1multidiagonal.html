The rank-1 operator with the single diagonal values at the signed offset offset: the building block of operators.

Operators with several diagonals, or on several axes, are built from these with operator+, operator* (composition) and operator% (direct product, the left operand's axes first). Only a diagonal whose coefficients don't factorize over the axes needs to be put into MultiDiagonal::diagonals directly.

Following the storage convention of MultiDiagonal, values[k] is the matrix element \(A_{k+o^-,\,k+o^+}\), i.e. \(\langle k|A|k+o\rangle\) for an upper diagonal ( \(o>0\)), and the dimension is values.size()+|offset|. Empty values give a structural zero of dimension |offset|, e.g. \(a\) for a cutoff of 1.

auto a {multidiagonal::diagonal(+1,{1.,std::sqrt(2.),std::sqrt(3.)})}; // a for a cutoff of 4
auto sm{multidiagonal::diagonal(+1,{1.})}; // σ⁻ = |0⟩⟨1|
auto n {hermitianConjugateOf(a) * a}; // composition: the number operator
auto jc{hermitianConjugateOf(sm) % a + sm % hermitianConjugateOf(a)}; // qubit on axis 0, mode on axis 1
