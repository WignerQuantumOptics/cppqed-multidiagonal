Tensor (outer) product of two complex multi-arrays.

Returns a MultiArray<dcomp, RANK1+RANK2> with extents concatenate(m1.extents, m2.extents). Element (i,j) of the result is func(m1[i], m2[j]); defaults to pointwise multiplication. Storage layout: result[i + stride*j] where stride = m1.dataView.size().

◆ incrementMultiIndex() [2/2]

template<size_t RANK>
auto & cppqedutils::incrementMultiIndex ( Extents< RANK > &  idx,
Extents< RANK >  extents 
)

Increments a multi-index in last-index-fastest order, in-place.

Note
The iteration order is the opposite of the memory order: storage is first-index-fastest (see multiarray::calculateStrides), so successive multi-indices are not adjacent in memory unless all axes but the last have extent 1.

The iteration pattern is: increment the last index; on overflow, reset it to zero and carry to the previous index. The loop termination guard is idx[0] != extents[0] — once the leading index overflows the array is exhausted. The final increment leaves idx in an out-of-bounds state, consistent with how unchecked iterators work.

◆ twoTimesRealPartOfSelf()

template<size_t TWO_TIMES_RANK>
void cppqedutils::twoTimesRealPartOfSelf ( MultiArrayView< dcomp, TWO_TIMES_RANK >  mav)

In-place replacement of a rank-2R matrix view mav with M + M† (twice its Hermitian part).

The diagonal becomes 2*re(mav(i,i)). For each pair i < j, mav(i,j) becomes mav(i,j) + conj(mav(j,i)), and mav(j,i) its conjugate. C++QED's master equation uses it to complete \((H_\text{eff}/i)\rho\) to \((H_\text{eff}/i)\rho + \rho\,(H_\text{eff}/i)^\dagger\), and to make \(\rho\) exactly Hermitian after each step. Operates directly on flat storage, so mav must be full and contiguous (checked by checkContiguous in debug builds).
